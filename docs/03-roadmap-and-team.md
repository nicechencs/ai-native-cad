# 03. 24 个月研发路线图、数据工程与团队配置

## 一、 切入策略（Beachhead Strategy）

避开立项初期正面硬刚十万级整车装配与全套国标二维工程图的泥潭，聚焦**精密机电、具身智能（机器人本体/灵巧手）、低空无人机、高性能液冷散热板与 CNC/增材混合制造**的高附加值结构件与百件级子系统。

---

## 二、 24 个月分阶段里程碑

### 第一阶段：MVP 核心闭环验证（M1 - M6）
* **核心目标**：跑通“声明式 DSL + 精确 B-Rep 内核 + WebGPU 双向视口 + VLM 自检闭环”。
* **关键交付**：
  1. 发布 **CAD-DSL v0.1** 语法规范与 LSP 语言服务器（覆盖草图、拉伸、旋转、扫掠、放样、圆角、抽壳、阵列、相切/同心约束）。
  2. 基于 Rust/C++ 封装 OCCT/Truck 几何服务，完成“视口点选拖拽 <-> 代码 AST 实时双向改写”。
  3. 上线多模态视觉自检 Agent，标准支架、法兰、壳体、非标夹具的自然语言/草图生成 STEP 合格率 > 95%。

### 第二阶段：混合隐式内核与实时物理融合（M7 - M14）
* **核心目标**：上线 GPU SDF 隐式场与实时力热仿真，建立相对传统 CAD 的代际优势。
* **关键交付**：
  1. 跑通 GPU SDF 引擎，支持永不失败的复杂变半径圆角、抽壳、晶格填充与流道生成。
  2. 集成 GPU Voxel FEA 与 CNC 刀具可达性/拔模斜度检查算子，实现载荷驱动自动轻量化生长。
  3. 交付 STEP 逆向特征识别导入与 Quad-NURBS 高质量导出管线 v1.0。

### 第三阶段：机电装配协同与企业级生态（M15 - M24）
* **核心目标**：升级为机电系统级协同设计平台。
* **关键交付**：
  1. 上线 3D 装配体可微运动学求解器（同轴、凸轮相切、齿轮啮合、连杆机构干涉包络检查）。
  2. 内置 ISO/GB 紧固件、轴承、电机、导轨标准件库，支持 AI 自动选型开孔。
  3. 打通 OpenUSD 机器人仿真管线，并基于纯文本 DSL 实现原生 `Git Diff / Merge` 工程版本管理。

## 三、 合成数据工厂（解决工业多模态数据荒）

1. **开源数据集逆向转译**：清洗 ABC Dataset（100 万 B-Rep 模型）、DeepCAD 与 Fusion 360 Gallery，通过特征识别与 VLM 反编译为 CAD-DSL 代码，仅保留 100% 编译通过且体积误差 < 0.1% 的高保真样本。
2. **程序化变异与物理仿真闭环（Procedural Augmentation）**：编写数百类机械零件元模板，随机采样尺寸、载荷与孔位拓扑，后台 GPU 集群自动执行有限元分析与 CNC 可达性打分，日产数万条**“规格契约 -> DSL 代码 -> 物理应力场 -> 工艺评分”**四元组强化学习数据。

## 五、 核心风险与工程兜底预案

* **风险 1：复杂隐式曲面转 STEP 出现奇异点或碎面**
  * *兜底方案*：常规规则结构（80% 场景）优先引导 AI 生成原生精确 B-Rep 算子实现零损耗输出；仅在复杂流道、仿生减重与晶格等 20% 区域启用 SDF，同时支持直出高精度 3MF 对接增材与五轴 CAM。
* **风险 2：超长代码脚本引发大模型空间干涉幻觉**
  * *兜底方案*：强制模块化子程序拆分（底座模块 + 安装耳模块 + 筋板模块），每个子模块编译时自动运行硬几何断言（Assertion，如最小壁厚校验、螺栓扳手作业空间无干涉检查）。
