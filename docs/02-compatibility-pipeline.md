# 02. 传统几何操作实现与工业格式双向兼容管线

## 一、 传统核心特征操作在新架构下的升维实现

抛弃传统历史树绝不意味着丧失精密机械操作能力。相反，**合并、阵列、相切、圆角、抽壳**在新架构中拥有更高的数学稳定性：

### 1. 合并（布尔并/差/交）与圆角过渡
* **传统痛点**：B-Rep 面-面求交（SSI）遇到微小碎面、擦边相切或零厚度流形时极易报错崩溃。
* **新架构实现**：
  * 硬布尔运算直接取极值 $\min(f_A(p), f_B(p))$，计算复杂度 $O(1)$，数学上永不失败。
  * 光滑合并采用 Smooth Minimum 算子，瞬间生成变半径光滑过渡圆角（Fillet Blend），亦可受局部应力场控制圆角大小。
  * 精密装配接口处由混合桥接器调用精确 B-Rep 布尔算子，确保锋利准确的配合边界。

### 2. 阵列（线性、圆周、路径与物理场驱动阵列）
* **传统痛点**：上万个阵列特征会复制海量 B-Rep 拓扑点边面，直接撑爆内存卡死。
* **新架构实现**：
  * 代码层支持标准循环与对称算子；隐式层通过**空间域折叠（Domain Repetition，坐标取模运算）**实现千万级微孔或晶格阵列而显存零增长。
  * 支持**场驱动非均匀阵列**：例如孔径与间距随温度场或应力场梯度自动连续缩放。

### 3. 相切与精确几何约束（同心、平行、垂直、G2 连续）
* **2D/3D 解析层硬约束**：声明式代码内置可微几何约束求解器（Autodiff + Levenberg-Marquardt），带方向正则项防止尺寸大改时发生相切翻转。
* **自由曲面与解析面相切**：在三维空间转化为接触点等值约束 $f_1(x)=f_2(x)=0$ 与法向量共线约束 $\nabla f_1(x) \parallel \nabla f_2(x)$，让仿生支撑筋以 G1 相切甚至 G2 曲率连续姿态自然生长在标准圆柱轴承座外壁上。

## 二、 现有工业 3D 格式双向兼容管线

兼容 STEP 是工业软件落地的生死线。系统通过**双向编译管线**打通上下游生态：

### 1. 外部文件导入（STEP / IGES -> 内部混合表示）
1. **精确拓扑读取**：解析外部 STEP 的点、边、面及解析曲面参数。
2. **几何深度学习逆向识别**：运行 **UV-Net / BRepNet** 图神经网络，自动识别哑几何（Dumb Geometry）中的机械语义特征（如 M6 沉头孔圆周阵列、轴承配合内孔、安装法兰面、倒角）。
3. **锁定配合区与参数化提取**：将关键配合面标记为 `Preserved B-Rep Regions`（禁止 AI 破坏公差），同时将孔位、轴距映射为可编辑 DSL 变量。

### 2. 标准格式导出（内部混合几何 -> STEP / 3MF / OpenUSD）
针对复杂隐式生成的自由结构，执行四步高质量曲面重构流水线：
1. **自适应等值面提取**：运行 Adaptive Dual Contouring 提取保留尖锐特征的水密网格（可直接导出高精度 **3MF / STL** 用于增材制造）。
2. **场对齐四边面重拓扑（Quad Remeshing）**：基于主曲率方向场对齐算法（*Instant Field-Aligned Meshes* 改进方案），生成奇异点极少、流线规整的纯四边面网格。
3. **SubD 转精确 G2 NURBS**：将四边面网格映射为 Catmull-Clark 细分曲面，再解析转换为分片少、无碎面的 G2 连续双三次 NURBS 大面。
4. **精确接口布尔替换与缝合（Sewing & Healing）**：切掉接口处的拟合近似面，替换为 L1 保留的原生精确圆柱面/平面并完成公差缝合，输出标准 **STEP (AP214 / AP242)**；同时支持一键导出带关节运动学与材质属性的 **OpenUSD** 对接 Isaac Sim / MuJoCo。
